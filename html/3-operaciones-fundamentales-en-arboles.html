Subtema 3. Operaciones fundamentales en árboles

Comprender la creación de nodos y las operaciones de inserción, búsqueda y eliminación, preservando las propiedades estructurales de los árboles.

Introducción

Los árboles permiten organizar información de manera jerárquica mediante nodos relacionados entre sí. Una vez comprendidos sus elementos y principales clasificaciones, es necesario estudiar las operaciones utilizadas para construir, consultar y modificar estas estructuras.

Las operaciones fundamentales incluyen la creación de nodos, inserción de elementos, búsqueda de valores, eliminación de nodos e identificación de relaciones jerárquicas.

En este subtema utilizaremos principalmente árboles binarios de búsqueda (BST), cuyas reglas de ordenamiento permiten comprender e implementar estas operaciones utilizando Python.

3.1 Creación de árboles y nodos

La creación de un árbol consiste en establecer una estructura jerárquica formada por nodos y conexiones entre ellos.

Un nodo es la unidad básica de un árbol. Contiene información y referencias hacia otros nodos, según las características de la estructura utilizada.

En un árbol binario, cada nodo puede contener tres componentes principales:

Valor

Información almacenada dentro del nodo.

Referencia izquierda

Conexión hacia el hijo izquierdo.

Referencia derecha

Conexión hacia el hijo derecho.

Representación de un nodo

Cuando un nodo todavía no posee hijos, las referencias izquierda y derecha pueden inicializarse con None.

Implementación en Python

class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None


raiz = Nodo(50)

print("Raíz:", raiz.valor)
Salida del programa 
Raíz: 50

La clase Nodo establece el valor y las referencias de cada elemento. La instrucción raiz = Nodo(50) crea el primer nodo del árbol.

Creación manual de un árbol binario

raiz = Nodo(50)

raiz.izquierdo = Nodo(30)
raiz.derecho = Nodo(70)

raiz.izquierdo.izquierdo = Nodo(20)
raiz.izquierdo.derecho = Nodo(40)

Árbol construido mediante referencias entre objetos.

La creación manual resulta útil para comprender la estructura, pero cuando se necesita agregar una gran cantidad de valores es recomendable implementar métodos de inserción.

3.2 Inserción de nuevos elementos

La inserción consiste en agregar un nuevo nodo dentro del árbol, respetando las reglas de organización de la estructura.

En un árbol binario de búsqueda, cada valor se compara con los nodos existentes para determinar dónde debe insertarse.

Valor menor

Se continúa hacia el subárbol izquierdo.

Valor mayor

Se continúa hacia el subárbol derecho.

Referencia vacía

Se crea el nuevo nodo en esa posición.

Ejemplo: inserción del valor 60

  1. Se compara 60 con la raíz 50.
  2. Como 60 es mayor que 50, se continúa hacia la derecha.
  3. Se compara 60 con 70.
  4. Como 60 es menor que 70, se continúa hacia la izquierda.
  5. La posición está vacía, por lo que se crea el nodo 60.

Implementación de inserción en Python

class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None


def insertar(raiz, valor):
    if raiz is None:
        return Nodo(valor)

    if valor < raiz.valor:
        raiz.izquierdo = insertar(raiz.izquierdo, valor)

    elif valor > raiz.valor:
        raiz.derecho = insertar(raiz.derecho, valor)

    return raiz


raiz = None

for valor in [50, 30, 70, 20, 40, 60]:
    raiz = insertar(raiz, valor)

print("Raíz:", raiz.valor)
print("Hijo izquierdo de 70:", raiz.derecho.izquierdo.valor)
Salida del programa 
Raíz: 50
Hijo izquierdo de 70: 60

Explicación del código

La función insertar() recibe la raíz del árbol o subárbol y el valor que debe agregarse.

Si encuentra una referencia None, crea un nuevo nodo. Si el valor es menor que el nodo actual, continúa por la izquierda; si es mayor, continúa por la derecha.

Recursividad: la función se llama a sí misma para recorrer los subárboles hasta localizar una posición disponible. En esta implementación, los valores duplicados se ignoran.

3.3 Búsqueda de elementos

La búsqueda es la operación que permite determinar si un valor se encuentra almacenado dentro de un árbol.

En un BST, las comparaciones permiten seleccionar la rama que podría contener el valor buscado, evitando recorrer innecesariamente otras partes de la estructura.

Proceso de búsqueda

  1. Se comienza desde la raíz.
  2. Se compara el valor buscado con el nodo actual.
  3. Si son iguales, la búsqueda termina exitosamente.
  4. Si el valor es menor, se continúa hacia la izquierda.
  5. Si es mayor, se continúa hacia la derecha.
  6. Si se alcanza una referencia vacía, el valor no existe.

Ejemplo: búsqueda del valor 40

Camino: 50 → 30 → 40

Implementación de búsqueda en Python

El siguiente ejemplo utiliza la variable raiz creada en el apartado anterior.

def buscar(raiz, valor):
    actual = raiz

    while actual is not None:
        if valor == actual.valor:
            return True

        if valor < actual.valor:
            actual = actual.izquierdo
        else:
            actual = actual.derecho

    return False


print(buscar(raiz, 40))
print(buscar(raiz, 90))
Salida del programa 
True
False

La función utiliza un ciclo while para desplazarse por el árbol. Devuelve True cuando encuentra el valor y False cuando llega a una referencia vacía.

Eficiencia de búsqueda

Organización del BST Complejidad temporal
Árbol equilibrado O(log n)
Árbol degenerado O(n)

3.4 Eliminación de nodos

La eliminación consiste en retirar un nodo del árbol sin alterar las propiedades que determinan su organización.

En un árbol binario de búsqueda existen tres casos principales, dependiendo de la cantidad de hijos del nodo que se desea eliminar.

Caso 1. Eliminación de un nodo hoja

Un nodo hoja no tiene hijos, por lo que puede eliminarse directamente sin reorganizar otros descendientes.

Antes de eliminar
Después de eliminar

Caso 2. Eliminación de un nodo con un hijo

Cuando un nodo tiene un único hijo, este ocupa la posición del nodo eliminado.

Antes:              Después:

    50                  50
      \                   \
      70                  60
     /
    60

Al eliminar el nodo 70, su único hijo 60 pasa a ocupar su posición.

Caso 3. Eliminación de un nodo con dos hijos

Cuando un nodo tiene dos hijos, debe reemplazarse utilizando un valor que permita mantener el ordenamiento del BST.

Sucesor inorden

Corresponde al menor valor del subárbol derecho. También es posible utilizar el predecesor inorden, que es el mayor valor del subárbol izquierdo.

Ejemplo: eliminación del valor 50

  1. Se identifica el nodo 50.
  2. Se localiza el menor valor del subárbol derecho: 60.
  3. El valor 50 se reemplaza por 60.
  4. Se elimina el nodo original que contenía 60.

El valor 60 sustituye al 50 y conserva las propiedades del BST.

Implementación de eliminación en Python

Este código utiliza la clase Nodo y la función insertar() definidas anteriormente. Se considera un árbol que contiene los valores 50, 30, 70, 20, 40, 60 y 80.

def eliminar(raiz, valor):
    if raiz is None:
        return None

    if valor < raiz.valor:
        raiz.izquierdo = eliminar(raiz.izquierdo, valor)

    elif valor > raiz.valor:
        raiz.derecho = eliminar(raiz.derecho, valor)

    else:
        # Caso: cero o un hijo
        if raiz.izquierdo is None:
            return raiz.derecho

        if raiz.derecho is None:
            return raiz.izquierdo

        # Caso: dos hijos
        sucesor = raiz.derecho

        while sucesor.izquierdo is not None:
            sucesor = sucesor.izquierdo

        raiz.valor = sucesor.valor

        raiz.derecho = eliminar(
            raiz.derecho,
            sucesor.valor
        )

    return raiz


# Crear el árbol del ejemplo
raiz = None
for valor in [50, 30, 70, 20, 40, 60, 80]:
    raiz = insertar(raiz, valor)

raiz = eliminar(raiz, 50)

print("Nueva raíz:", raiz.valor)
Salida del programa 
Nueva raíz: 60

La función utiliza recursividad para localizar el nodo y reorganizar las conexiones necesarias. Es importante actualizar la referencia de la raíz con el valor devuelto, ya que esta puede cambiar después de eliminar un elemento.

3.5 Identificación de nodos padres, hijos y hojas

Además de insertar, buscar y eliminar, es importante identificar las relaciones jerárquicas entre los elementos del árbol.

Raíz

Nodo principal que no tiene padre.

Padre

Nodo que posee uno o varios hijos directos.

Hijos

Nodos conectados directamente a un padre.

Hojas

Nodos que no tienen descendientes directos.

Identificación de la raíz

print("Raíz:", raiz.valor)

La variable raiz mantiene una referencia al nodo principal del árbol.

Identificación de los hijos

if raiz.izquierdo is not None:
    print("Hijo izquierdo:", raiz.izquierdo.valor)

if raiz.derecho is not None:
    print("Hijo derecho:", raiz.derecho.valor)

Antes de consultar un hijo debe verificarse que su referencia no sea None.

Identificación de nodos hoja

def es_hoja(nodo):
    if nodo is None:
        return False

    return (
        nodo.izquierdo is None
        and nodo.derecho is None
    )


print(es_hoja(raiz.izquierdo.izquierdo))
Salida: True

El nodo consultado no tiene hijos y, por lo tanto, es una hoja.

Identificación de un nodo padre

La clase utilizada no almacena una referencia directa hacia el padre. Por ello, podemos recorrer el BST para localizar el nodo que contiene al hijo buscado.

def buscar_padre(raiz, valor):
    actual = raiz
    padre = None

    while actual is not None:
        if valor == actual.valor:
            return padre

        padre = actual

        if valor < actual.valor:
            actual = actual.izquierdo
        else:
            actual = actual.derecho

    return None


padre = buscar_padre(raiz, 40)

if padre is not None:
    print("Padre:", padre.valor)
else:
    print("No se encontró un padre")
Salida del programa 
Padre: 30

Importancia de las relaciones jerárquicas

Relación Utilidad
Raíz Permite iniciar las operaciones del árbol.
Padre Facilita modificar conexiones entre nodos.
Hijo Permite desplazarse por las ramas.
Hoja Identifica el final de una rama.
Subárbol Permite trabajar con una sección de la estructura.

3.6 Importancia de mantener la estructura y sus propiedades

Las operaciones sobre árboles deben preservar las características que permiten su correcto funcionamiento.

Por ejemplo, un árbol binario debe conservar un máximo de dos hijos por nodo. Un BST, además, debe mantener sus reglas de ordenamiento.

Comparación de estructuras

BST válido 
       50
      /  \
     30   70
    / \   / \
   20 40 60 80

Los valores respetan el ordenamiento de todos los subárboles.

BST inválido 
       50
      /  \
     30   70
         /
        40

El valor 40 es menor que 50, pero se encuentra dentro de su subárbol derecho.

Propiedades que deben conservarse

Organización

Las conexiones respetan el tipo de árbol utilizado.

Ordenamiento

Los valores de un BST conservan las reglas de comparación.

Integridad

Las modificaciones no deben provocar pérdida accidental de subárboles.

Conectividad

Los nodos mantienen sus conexiones dentro de una estructura válida.

Ausencia de ciclos

Las referencias no generan recorridos circulares.

Balanceo

En estructuras AVL, las modificaciones deben preservar o recuperar el equilibrio.

Ejemplo práctico: registro de identificadores

Supongamos que una aplicación administra identificadores numéricos organizados mediante un BST.

  1. Registrar: el nuevo identificador se inserta respetando el ordenamiento.
  2. Consultar: se realizan comparaciones para localizar el identificador.
  3. Eliminar: se retira el identificador y se reorganizan las conexiones necesarias.

Ejemplo integrador en Python

El siguiente programa reúne las operaciones fundamentales de inserción, búsqueda y eliminación en un árbol binario de búsqueda. Puede ejecutarse de manera independiente.

class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None


def insertar(raiz, valor):
    if raiz is None:
        return Nodo(valor)

    if valor < raiz.valor:
        raiz.izquierdo = insertar(raiz.izquierdo, valor)

    elif valor > raiz.valor:
        raiz.derecho = insertar(raiz.derecho, valor)

    return raiz


def buscar(raiz, valor):
    while raiz is not None:
        if valor == raiz.valor:
            return True

        if valor < raiz.valor:
            raiz = raiz.izquierdo
        else:
            raiz = raiz.derecho

    return False


def eliminar(raiz, valor):
    if raiz is None:
        return None

    if valor < raiz.valor:
        raiz.izquierdo = eliminar(raiz.izquierdo, valor)

    elif valor > raiz.valor:
        raiz.derecho = eliminar(raiz.derecho, valor)

    else:
        if raiz.izquierdo is None:
            return raiz.derecho

        if raiz.derecho is None:
            return raiz.izquierdo

        sucesor = raiz.derecho

        while sucesor.izquierdo is not None:
            sucesor = sucesor.izquierdo

        raiz.valor = sucesor.valor

        raiz.derecho = eliminar(
            raiz.derecho,
            sucesor.valor
        )

    return raiz


# Crear el árbol
raiz = None

valores = [50, 30, 70, 20, 40, 60, 80]

for valor in valores:
    raiz = insertar(raiz, valor)


# Buscar elementos
print("Buscar 40:", buscar(raiz, 40))
print("Buscar 90:", buscar(raiz, 90))


# Eliminar un elemento
raiz = eliminar(raiz, 50)

print("Nueva raíz:", raiz.valor)
print("Buscar 50:", buscar(raiz, 50))

Resultado de la ejecución

Buscar 40: True
Buscar 90: False
Nueva raíz: 60
Buscar 50: False

Análisis del resultado

  • El programa crea un BST a partir de siete valores.
  • La búsqueda del valor 40 devuelve True porque existe en el árbol.
  • La búsqueda del valor 90 devuelve False porque no está registrado.
  • Al eliminar 50, el sucesor inorden 60 ocupa su posición como nueva raíz.
  • La última consulta confirma que el valor 50 ya no pertenece a la estructura.

Síntesis

Las operaciones fundamentales permiten crear, modificar y consultar árboles durante la ejecución de un programa.

La inserción incorpora nuevos nodos, la búsqueda permite localizar valores y la eliminación retira elementos sin perder las propiedades estructurales. La identificación de raíces, padres, hijos y hojas facilita comprender las relaciones jerárquicas.

En los árboles binarios de búsqueda, mantener el ordenamiento es indispensable. La eficiencia de las operaciones depende de la altura y organización del árbol. Estos conocimientos constituyen la base para estudiar los recorridos de árboles.
