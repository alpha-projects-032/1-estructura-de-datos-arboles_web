Subtema 5. Implementación y aplicaciones de árboles en Python

Implementar árboles mediante clases y objetos en Python, desarrollar operaciones de búsqueda y recorrido, e identificar sus principales aplicaciones informáticas.

Introducción

Los árboles son estructuras de datos no lineales que permiten organizar información mediante relaciones jerárquicas. Su implementación en un lenguaje de programación permite construir sistemas capaces de almacenar, buscar, insertar, eliminar y procesar información de manera organizada.

En Python, los árboles pueden desarrollarse mediante clases y objetos, aprovechando los principios de la programación orientada a objetos para representar nodos y establecer conexiones entre ellos.

En este subtema se desarrollará la implementación de árboles binarios y árboles binarios de búsqueda (BST), utilizando métodos de inserción, búsqueda y recorrido, además de identificar sus aplicaciones prácticas en sistemas informáticos.

5.1 Representación de un nodo mediante una clase Node

Un nodo es el componente fundamental de un árbol. Almacena un valor y contiene referencias que permiten establecer conexiones con otros nodos.

En un árbol binario, cada nodo dispone de tres atributos principales:

value

Almacena el valor o información del nodo.

left

Referencia hacia el hijo izquierdo.

right

Referencia hacia el hijo derecho.

Representación gráfica de un nodo

Implementación de la clase Node

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


# Crear un nodo
node = Node(50)

print("Valor:", node.value)
print("Hijo izquierdo:", node.left)
print("Hijo derecho:", node.right)
Salida del programa 
Valor: 50
Hijo izquierdo: None
Hijo derecho: None

Explicación del código

La clase Node define la estructura básica de cada elemento. Su método __init__() recibe el valor y establece las referencias iniciales.

Los atributos left y right contienen inicialmente None. Cuando se asigna otro objeto Node, se establece una conexión entre nodos del árbol.

5.2 Implementación de un árbol binario mediante una clase BinaryTree

Un árbol binario puede implementarse mediante una clase que administre su raíz y permita establecer conexiones entre nodos.

La clase BinaryTree representa el árbol completo, mientras que la clase Node representa cada uno de sus elementos.

Estructura de un árbol binario

Árbol binario construido mediante referencias entre objetos.

Implementación en Python

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


class BinaryTree:
    def __init__(self, value):
        self.root = Node(value)


# Crear el árbol
tree = BinaryTree("A")

# Agregar nodos
tree.root.left = Node("B")
tree.root.right = Node("C")

tree.root.left.left = Node("D")
tree.root.left.right = Node("E")


# Consultar la estructura
print("Raíz:", tree.root.value)
print("Hijo izquierdo:", tree.root.left.value)
print("Hijo derecho:", tree.root.right.value)
Salida del programa 
Raíz: A
Hijo izquierdo: B
Hijo derecho: C

La clase BinaryTree utiliza el atributo root para almacenar la referencia al nodo principal. Los demás nodos se agregan mediante las propiedades left y right.

Diferencias entre las clases

Clase Responsabilidad
Node Representar un elemento individual y sus referencias.
BinaryTree Administrar la raíz y representar el árbol completo.

En este ejemplo, la construcción es manual y no utiliza reglas de comparación. Por lo tanto, representa un árbol binario general, no necesariamente un árbol binario de búsqueda.

5.3 Implementación básica de un árbol binario de búsqueda (BST)

Un árbol binario de búsqueda (BST) organiza los valores mediante reglas de comparación, permitiendo decidir si un elemento debe ubicarse en el subárbol izquierdo o derecho.

Subárbol izquierdo

Contiene valores menores que el nodo actual.

Subárbol derecho

Contiene valores mayores que el nodo actual.

Las reglas deben cumplirse en todos los subárboles. Para este ejemplo se utilizará un BST que no admite valores duplicados.

Representación del BST

Los valores menores se encuentran a la izquierda y los mayores a la derecha de cada nodo.

Implementación de BinarySearchTree

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def insert(self, value):
        new_node = Node(value)

        if self.root is None:
            self.root = new_node
            return

        current = self.root

        while True:
            if value == current.value:
                return

            if value < current.value:
                if current.left is None:
                    current.left = new_node
                    return

                current = current.left

            else:
                if current.right is None:
                    current.right = new_node
                    return

                current = current.right


# Crear el árbol
bst = BinarySearchTree()

# Insertar valores
for value in [50, 30, 70, 20, 40, 60, 80]:
    bst.insert(value)

print("Raíz:", bst.root.value)
print("Hijo izquierdo:", bst.root.left.value)
print("Hijo derecho:", bst.root.right.value)
Salida del programa 
Raíz: 50
Hijo izquierdo: 30
Hijo derecho: 70

Proceso de inserción

Al insertar la secuencia [50, 30, 70, 20, 40, 60, 80], se realizan las siguientes operaciones:

  1. El valor 50 se convierte en la raíz.
  2. 30 se inserta a la izquierda de 50.
  3. 70 se inserta a la derecha de 50.
  4. 20 se inserta a la izquierda de 30.
  5. 40 se inserta a la derecha de 30.
  6. 60 se inserta a la izquierda de 70.
  7. 80 se inserta a la derecha de 70.

El BST resultante tiene una distribución equilibrada, pero esta implementación no realiza balanceo automático. El orden de inserción puede afectar la altura del árbol.

5.4 Métodos de inserción, búsqueda y recorrido

Una de las ventajas de implementar árboles mediante clases es que las operaciones pueden integrarse como métodos de la propia estructura.

De esta forma, el objeto que representa al árbol administra su información sin necesidad de manipular directamente todos sus nodos desde el programa principal.

Método de inserción

El método insert() permite agregar nuevos valores respetando las reglas del BST.

bst.insert(25)
bst.insert(65)

El valor 25 se incorpora como hijo derecho de 20 y el valor 65 como hijo derecho de 60.

Método de búsqueda

El método search() permite determinar si un valor existe dentro del árbol. El siguiente método se incorpora dentro de la clase BinarySearchTree:

def search(self, value):
    current = self.root

    while current is not None:
        if value == current.value:
            return True

        if value < current.value:
            current = current.left
        else:
            current = current.right

    return False

Una vez incorporado el método a la clase, puede utilizarse de la siguiente manera:

print(bst.search(40))
print(bst.search(90))
Salida 
True
False

Métodos de recorrido

Los recorridos permiten obtener los valores de un árbol siguiendo un orden específico. En esta implementación, los métodos devuelven listas para facilitar su reutilización.

Preorden: raíz, izquierda, derecha
def preorder(self):
    result = []

    def traverse(node):
        if node is not None:
            result.append(node.value)
            traverse(node.left)
            traverse(node.right)

    traverse(self.root)
    return result
Inorden: izquierda, raíz, derecha
def inorder(self):
    result = []

    def traverse(node):
        if node is not None:
            traverse(node.left)
            result.append(node.value)
            traverse(node.right)

    traverse(self.root)
    return result
Postorden: izquierda, derecha, raíz
def postorder(self):
    result = []

    def traverse(node):
        if node is not None:
            traverse(node.left)
            traverse(node.right)
            result.append(node.value)

    traverse(self.root)
    return result

Los métodos anteriores deben definirse dentro de la clase BinarySearchTree. Utilizan una función interna llamada traverse(), encargada de visitar recursivamente los nodos.

Resultados de los recorridos

Considerando el BST original de siete nodos, antes de insertar 25 y 65:

Recorrido Resultado
Preorden 50, 30, 20, 40, 70, 60, 80
Inorden 20, 30, 40, 50, 60, 70, 80
Postorden 20, 40, 30, 60, 80, 70, 50

Complejidad de las operaciones

Operación BST equilibrado BST degenerado
Inserción O(log n) O(n)
Búsqueda O(log n) O(n)
Recorrido completo O(n) O(n)

La eficiencia de búsqueda e inserción depende de la altura del árbol. Un BST convencional no garantiza mantener su equilibrio después de múltiples inserciones.

5.5 Organización jerárquica de carpetas y archivos

Una de las aplicaciones más representativas de los árboles es la organización de carpetas y archivos dentro de un sistema operativo.

Las carpetas pueden contener archivos y otras carpetas, estableciendo relaciones jerárquicas.

Ejemplo: organización de un proyecto

ProyectoPython/
├── documentos/
│   ├── informe.pdf
│   └── manual.docx
├── codigo/
│   ├── main.py
│   └── funciones.py
└── recursos/
    ├── imagenes/
    └── datos.csv
Nodo raíz

ProyectoPython representa el elemento principal de la jerarquía mostrada.

Nodos internos

Las carpetas con contenido representan nodos que poseen hijos.

Nodos hoja

Los archivos y carpetas sin contenido representan nodos sin hijos.

Representación mediante diccionarios

Una alternativa introductoria para representar árboles generales consiste en utilizar diccionarios anidados de Python.

proyecto = {
    "nombre": "ProyectoPython",
    "hijos": [
        {
            "nombre": "documentos",
            "hijos": [
                {"nombre": "informe.pdf", "hijos": []},
                {"nombre": "manual.docx", "hijos": []}
            ]
        },
        {
            "nombre": "codigo",
            "hijos": [
                {"nombre": "main.py", "hijos": []},
                {"nombre": "funciones.py", "hijos": []}
            ]
        },
        {
            "nombre": "recursos",
            "hijos": [
                {"nombre": "imagenes", "hijos": []},
                {"nombre": "datos.csv", "hijos": []}
            ]
        }
    ]
}

Esta representación permite que cada nodo tenga una cantidad variable de hijos, a diferencia de los árboles binarios.

Recorrido de la estructura jerárquica

def mostrar_arbol(nodo, nivel=0):
    espacio = "    " * nivel

    print(espacio + nodo["nombre"])

    for hijo in nodo["hijos"]:
        mostrar_arbol(hijo, nivel + 1)


mostrar_arbol(proyecto)

Salida del programa

ProyectoPython

        manual.docx
    codigo
        main.py
        funciones.py
    recursos
        imagenes
        datos.csv

La función mostrar_arbol() recorre recursivamente los nodos y utiliza espacios de indentación para representar visualmente los niveles de la jerarquía.

5.6 Aplicaciones de árboles en sistemas informáticos

Los árboles se utilizan en numerosas áreas de la informática debido a su capacidad para organizar información y representar relaciones jerárquicas.

Sistemas de archivos

Organizan carpetas, subcarpetas y documentos mediante relaciones jerárquicas.

Sistemas de búsqueda

Utilizan BST y estructuras balanceadas para localizar valores mediante comparaciones.

Bases de datos

Emplean árboles B y B+ para implementar índices y facilitar el acceso a registros.

Compiladores e intérpretes

Utilizan árboles de sintaxis abstracta para representar la estructura lógica de instrucciones.

Inteligencia artificial

Los árboles de decisión representan condiciones y resultados para clasificación y predicción.

Sistemas de organización

Representan organigramas, catálogos, categorías y menús jerárquicos.

Comparación de aplicaciones

Aplicación Tipo de árbol Función
Sistemas de archivos Árbol general Organización de directorios.
Búsqueda de valores BST o AVL Localización de información.
Índices de bases de datos B y B+ Acceso eficiente a registros.
Compiladores Árbol de sintaxis abstracta Representación de instrucciones.
Clasificación con IA Árbol de decisión Evaluación de condiciones.
Sistemas de prioridad Montículo binario Administración de prioridades.

La selección de un árbol debe considerar la organización de los datos, las operaciones que necesita ejecutar la aplicación y las características del sistema informático.

Ejemplo integrador en Python

El siguiente programa implementa una clase BinarySearchTree con los métodos de inserción, búsqueda y recorridos preorden, inorden y postorden.

El código es completo y puede ejecutarse directamente en Python.

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    # Insertar un elemento
    def insert(self, value):
        new_node = Node(value)

        if self.root is None:
            self.root = new_node
            return

        current = self.root

        while True:
            if value == current.value:
                return

            if value < current.value:
                if current.left is None:
                    current.left = new_node
                    return

                current = current.left

            else:
                if current.right is None:
                    current.right = new_node
                    return

                current = current.right

    # Buscar un elemento
    def search(self, value):
        current = self.root

        while current is not None:
            if value == current.value:
                return True

            if value < current.value:
                current = current.left
            else:
                current = current.right

        return False

    # Recorrido preorden
    def preorder(self):
        result = []

        def traverse(node):
            if node is not None:
                result.append(node.value)
                traverse(node.left)
                traverse(node.right)

        traverse(self.root)
        return result

    # Recorrido inorden
    def inorder(self):
        result = []

        def traverse(node):
            if node is not None:
                traverse(node.left)
                result.append(node.value)
                traverse(node.right)

        traverse(self.root)
        return result

    # Recorrido postorden
    def postorder(self):
        result = []

        def traverse(node):
            if node is not None:
                traverse(node.left)
                traverse(node.right)
                result.append(node.value)

        traverse(self.root)
        return result


# Crear un árbol binario de búsqueda
tree = BinarySearchTree()

# Insertar valores
values = [50, 30, 70, 20, 40, 60, 80]

for value in values:
    tree.insert(value)


# Consultar elementos
print("Buscar 40:", tree.search(40))
print("Buscar 90:", tree.search(90))


# Ejecutar recorridos
print("Preorden:", tree.preorder())
print("Inorden:", tree.inorder())
print("Postorden:", tree.postorder())

Resultado de la ejecución

Buscar 40: True
Buscar 90: False
Preorden: [50, 30, 20, 40, 70, 60, 80]
Inorden: [20, 30, 40, 50, 60, 70, 80]
Postorden: [20, 40, 30, 60, 80, 70, 50]

Análisis del resultado

  • El programa crea un BST a partir de siete valores numéricos.
  • El método insert() organiza automáticamente los valores respetando las reglas de comparación.
  • El método search() identifica si un valor existe dentro del árbol.
  • Los métodos de recorrido devuelven listas con los valores en diferentes órdenes.
  • El código puede ampliarse incorporando eliminación, cálculo de altura, identificación de hojas y recorrido por niveles.

Síntesis

La implementación de árboles en Python puede realizarse mediante clases y objetos, utilizando referencias para representar las relaciones entre nodos.

La clase Node define cada elemento, mientras que BinaryTree y BinarySearchTree permiten administrar la estructura completa.

Los métodos de inserción, búsqueda y recorrido facilitan la manipulación de información jerárquica y permiten reutilizar las operaciones dentro de diferentes aplicaciones.

Los árboles tienen aplicaciones relevantes en sistemas de archivos, mecanismos de búsqueda, bases de datos, compiladores, inteligencia artificial y sistemas de organización de información.
