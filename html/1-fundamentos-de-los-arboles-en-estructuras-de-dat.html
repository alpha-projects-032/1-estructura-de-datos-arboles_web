Estructuras de datos no lineales

Subtema 1. Fundamentos de los árboles en estructuras de datos

Comprender la organización jerárquica de los árboles, sus elementos fundamentales, propiedades y diferencias respecto a las estructuras lineales.

Introducción

En el desarrollo de software, no toda la información puede organizarse mediante estructuras lineales como listas, pilas o colas. Existen situaciones en las que los datos mantienen relaciones jerárquicas, donde un elemento principal se conecta con otros elementos subordinados.

Por ejemplo, los sistemas de archivos organizan carpetas y subcarpetas, las instituciones representan sus departamentos mediante jerarquías y las aplicaciones informáticas utilizan categorías y subcategorías.

Para representar estas relaciones se utilizan los árboles, estructuras de datos no lineales que permiten organizar información mediante nodos conectados entre sí.

1.1 Concepto de árbol como estructura de datos no lineal

Un árbol es una estructura de datos no lineal formada por un conjunto de elementos denominados nodos, conectados mediante relaciones llamadas aristas.

A diferencia de las estructuras lineales, donde los elementos se organizan secuencialmente, un árbol establece relaciones jerárquicas entre sus componentes.

En un árbol con raíz, existe un nodo principal desde el cual se originan las conexiones hacia los demás nodos.

Características principales

Organización jerárquica

Los elementos se distribuyen mediante relaciones de dependencia.

Nodo principal

Existe una raíz desde la cual se organiza la estructura.

Relaciones padre-hijo

Cada nodo, excepto la raíz, tiene exactamente un padre.

Ausencia de ciclos

Las conexiones no forman caminos cerrados.

Ejemplo de un árbol

Representación de un árbol con siete nodos y tres niveles.

El nodo A es la raíz. Los nodos B y C son sus hijos, mientras que D, E, F y G son las hojas del árbol.

1.2 Características y organización jerárquica

La organización jerárquica permite establecer relaciones de dependencia entre los nodos de un árbol. Cada nodo puede contener información y conexiones hacia otros nodos situados en niveles inferiores.

Relación padre-hijo

Un nodo se conecta directamente con otro situado en el siguiente nivel. A es padre de B y C.

Relación entre hermanos

Dos o más nodos que comparten el mismo padre. B y C son hermanos.

Antepasados y descendientes

Un nodo es antepasado de otro cuando pertenece al camino desde la raíz hasta ese nodo.

Subárbol

Estructura formada por un nodo y todos sus descendientes. B, D y E constituyen un subárbol.

Ejemplo práctico: organización institucional

Una institución puede representar su estructura organizativa mediante un árbol, estableciendo relaciones entre la dirección, los departamentos y las áreas.

La Dirección constituye la raíz. Los departamentos son sus hijos y las áreas de Docencia e Investigación dependen directamente del Departamento Académico.

1.3 Elementos fundamentales de un árbol

Para comprender el funcionamiento de un árbol, es necesario identificar los componentes que conforman su estructura.

Elemento Definición Ejemplo
Nodo Elemento que almacena información dentro del árbol. A, B, C
Raíz Nodo principal que no tiene padre. A
Arista Conexión entre dos nodos. A–B
Padre Nodo que tiene uno o varios hijos directos. B es padre de D
Hijo Nodo conectado directamente a un padre. D es hijo de B
Hermanos Nodos que comparten el mismo padre. D y E
Hoja Nodo que no tiene hijos. D, E, F, G
Nodo interno Nodo que tiene al menos un hijo. A, B, C
Subárbol Nodo junto con todos sus descendientes. B, D, E

Propiedad fundamental

Todo árbol no vacío con n nodos contiene exactamente n − 1 aristas.

Aristas = n − 1

Si el árbol tiene siete nodos, entonces contiene 7 − 1 = 6 aristas.

1.4 Conceptos de nivel, profundidad, altura y grado

Los árboles poseen propiedades que permiten describir su organización, tamaño y complejidad estructural.

Nivel

Posición de un nodo dentro de la jerarquía. Utilizaremos el nivel 0 para la raíz.

Profundidad

Cantidad de aristas desde la raíz hasta un nodo.

Altura

Cantidad de aristas del camino descendente más largo desde un nodo hasta una hoja.

Grado

Cantidad de hijos directos que posee un nodo.

Representación por niveles

N0: nivel cero; N1: nivel uno; N2: nivel dos.

Propiedad Valor
Nivel de A 0
Nivel de B y C 1
Nivel de D, E, F y G 2
Profundidad de E 2 aristas
Altura de B 1 arista
Altura del árbol 2 aristas
Grado de C 2
Grado de G 0
Diferencia importante

La altura del árbol es de dos aristas, mientras que la estructura presenta tres niveles: 0, 1 y 2. La altura no debe confundirse con la cantidad de niveles.

1.5 Diferencias entre estructuras lineales y árboles

Las estructuras lineales almacenan los elementos siguiendo una secuencia, mientras que los árboles permiten establecer relaciones jerárquicas. Esta diferencia influye en cómo se representan, consultan y procesan los datos.

Estructura lineal

Los elementos siguen una secuencia.

Estructura de árbol

Los elementos se relacionan por jerarquías.

Característica Estructuras lineales Árboles
Organización Secuencial Jerárquica
Relaciones Entre posiciones de una secuencia Entre padres e hijos
Nodo raíz No existe Existe
Recorrido Generalmente secuencial Diferentes órdenes
Ejemplos Listas, pilas y colas Árboles generales y binarios
Aplicaciones Turnos, historiales y registros Directorios, categorías y jerarquías

Caso práctico: plataforma académica

Supongamos que una plataforma necesita almacenar los nombres de 100 participantes y organizar programas académicos, asignaturas y unidades de aprendizaje.

Utilizando una lista

Es posible almacenar los nombres de los participantes secuencialmente.

Utilizando un árbol

Es posible representar las relaciones entre programas, asignaturas y unidades.

1.6 Representación gráfica de árboles

La representación gráfica permite visualizar cómo se relacionan los nodos dentro de una estructura jerárquica. Generalmente, los árboles se dibujan colocando la raíz en la parte superior y distribuyendo los descendientes hacia abajo.

Ejemplo: sistema de archivos

Proyecto/
│
├── documentos/
│   ├── informe.docx
│   └── manual.pdf
│
├── codigo/
│   ├── principal.py
│   └── funciones.py
│
└── recursos/
    ├── imagenes/
    └── datos.csv

Interpretación de la estructura

  • Proyecto: raíz de la jerarquía representada.
  • documentos, codigo y recursos: hijos directos de la raíz.
  • informe.docx y manual.pdf: hijos de documentos.
  • principal.py y funciones.py: hijos de codigo.
  • Archivos: representan nodos hoja.
  • Carpetas: pueden representar nodos internos cuando contienen elementos.

Esta representación facilita el diseño de algoritmos que recorren directorios, buscan archivos o procesan información estructurada jerárquicamente.

Ejemplo introductorio en Python

Aunque posteriormente estudiaremos la implementación formal de árboles mediante clases, podemos comenzar representando una jerarquía sencilla utilizando diccionarios de Python.

arbol = {
    "nombre": "Proyecto",
    "hijos": [
        {
            "nombre": "Documentos",
            "hijos": [
                {"nombre": "Informe", "hijos": []},
                {"nombre": "Manual", "hijos": []}
            ]
        },
        {
            "nombre": "Código",
            "hijos": [
                {"nombre": "Principal.py", "hijos": []}
            ]
        }
    ]
}

print(arbol["nombre"])

for hijo in arbol["hijos"]:
    print(hijo["nombre"])

Explicación del código

Diccionario principal

Representa la raíz del árbol y contiene las claves nombre e hijos.

Clave nombre

Almacena la información asociada con cada nodo.

Clave hijos

Contiene una lista de diccionarios que representan los descendientes directos.

Ciclo for

Recorre los hijos directos de la raíz y muestra sus nombres.

Salida del programa

Proyecto
Documentos
Código

Este ejemplo representa una jerarquía mediante estructuras básicas de Python. Posteriormente se implementarán árboles utilizando clases, objetos y referencias entre nodos.

Síntesis

Los árboles son estructuras de datos no lineales que organizan la información jerárquicamente mediante nodos y aristas.

Sus elementos principales incluyen la raíz, los nodos internos, las hojas y las relaciones entre padres e hijos. Propiedades como nivel, profundidad, altura y grado permiten describir su organización.

A diferencia de las estructuras lineales, los árboles permiten representar relaciones de dependencia y son especialmente útiles en sistemas de archivos, estructuras organizativas y clasificación jerárquica de información.
